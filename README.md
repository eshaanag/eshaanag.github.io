# Eshaan Agrawal Portfolio

Static GitHub Pages deployment of Eshaan Agrawal's engineering portfolio.

## What It Shows

The portfolio presents selected work across full-stack engineering, AI,
startups, and security through a responsive single-page experience.

## Tech Stack

- Static HTML export
- Generated Next.js assets
- GitHub Pages
- Google Analytics

## View Live

https://eshaanag.github.io/

## Preview Locally

```bash
git clone https://github.com/eshaanag/eshaanag.github.io.git
cd eshaanag.github.io
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Deployment Note

This repository contains the generated static deployment. Source-level changes
should be made in the portfolio source project and exported again before
publishing here.
